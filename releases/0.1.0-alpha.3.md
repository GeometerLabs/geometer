# Geometer 0.1.0-alpha.3

**Released DATE-TO-BE-SET-AT-PUBLISH.** The third public alpha, and the first made for builders who run agents for shops. Free to download, no account.

## What's new since 0.1.0-alpha.2

- **Geometer for builders.** This release is made for people who build agents for local shops and run them on their own server. The terminal files and the Guard image are what you need; the agents repository (https://github.com/GeometerLabs/agents) holds the templates, the deploy bundle, the panel and the Claude Code plugin.
- **The Mac app and the browser workspace are gone.** There is no `.dmg` and no workspace any more. Your local interface is the panel in the agents repository, its `geometer` command and the Claude Code plugin. `geo open` and the local API went with the workspace. The `geo` terminal command stays for checking an agent (`geo check`, `geo ci`).
- **Guard needs the Geometer licence to run a shop.** The Guard image (`ghcr.io/geometerlabs/geo-guard:0.1.0-alpha.3`) refuses to start a shop's configuration that has no `[licence]` block. With no lease, or a lease that does not list the shop, it takes no new work for that shop; refunds, cancellations and reads still go through. The `geo-guard` in the terminal download has no licence check: it is for trying your agent on your own computer.
- **A free trial for builders.** Pairing a server gives your account one trial of 30 days for up to three client businesses. After that, the builder licence applies (see https://geometer.dev/docs/plans-and-prices).
- **One-step install of a server.** `install.sh` in the agents repository sets up Docker, the Guard image, the deploy service, HTTPS and the panel from two answers: your domain and a pairing code from geometer.dev/account.
- **Your own agents.** `geometer agent add`, `agent set` and `agent crash-test` run your own agent, with your own command, behind real Guards and stand-in services with things going wrong on purpose, and say which situations it held. `agent go-live` writes a go-live certificate for the client.
- **Owner approvals.** A call above the shop's limit is held by Guard and the shop owner is asked once on WhatsApp. Approval can require several named people. After an owner says no, Guard refuses the identical call at once for 24 hours and asks nobody again (HTTP 403, `reason_code: denied_by_approver`): your agent should stop, not try another way.
- **Self-hosted models.** `geo-model-gateway` is in the terminal download. A builder who hosts a model runs it in front of the model, and the deploy bundle's model Guard points at it. Its Docker image is not published yet; the program is in the download.
- **Fixes.** `geo guard stop` waits for Guard to finish and says so if one does not exit, so a `start` right after a `stop` no longer finds a Guard that is still stopping. A check that runs out of disk, or loses Docker, cleans up its containers; `geo gc` stops a stuck worker. Guard's connection to PostgreSQL can use TLS.

Everything from 0.1.0-alpha.2 that checks your agent (`geo check`, `geo ci`, `geo mcp`, the framework support on Works with) is still here.

## Check your download

Download `SHA256SUMS` into the same folder as the file, then:

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing     # macOS
sha256sum -c SHA256SUMS --ignore-missing         # Linux
```

Each line should end in `OK`. `release.json` lists every file with its platform, size and digest, and says that nothing in this release is signed or notarized.

## Known limits

The full list is on the [Alpha limits](https://geometer.dev/docs/alpha-limits) page. The main ones:

- **Not signed by Apple.** Apple silicon only on macOS; no Intel Macs, no Windows.
- **Guard is for trying in development and staging.** It has not been qualified for production traffic, and the image is not signed.
- **Agents Geometer can run** are those whose tools it can find and simulate. When it cannot, it says what is missing instead of reporting a clean result.
- **Outside services and models are simulated.** A check shows how your agent behaves against those stand-ins, not against the real services or a real model.
- **Not yet tried on a clean Mac.** Installing on a Mac with no Docker and no Homebrew, and the Docker offers of `geo doctor --fix`, have not been tested on a real clean computer.
- Six qualification cases run on demand, not in the release gate. R4 (the gateway) no longer has an independent-application case in the gate; it runs on owned fixtures only. R3 and R5 keep an independent application.
- Geometer has been used by its own team only. Your reports decide what we fix first. Contact: hello@geometer.dev.
