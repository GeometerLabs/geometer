# Geometer 0.1.0-alpha.2

**Released 29 October 2026.** The second public alpha. Free to download, no account, no telemetry.

## What's new since 0.1.0-alpha.1

- **More agents it can check.** Geometer now watches the tools of agents written with the
  OpenAI Agents SDK, Mastra, LangGraph and LangChain, Pydantic AI, CrewAI, Strands Agents,
  Google ADK, LlamaIndex, smolagents, Agno, Microsoft Agent Framework, Microsoft AutoGen,
  Haystack, the Vercel AI SDK, Temporal and the Claude Agent SDK (TypeScript and Python), in
  Python and in Node. The [Works with](https://geometer.dev/docs/works-with) page says, for each
  one, whether it is Supported, Supported with limits, Partial or Not yet, and what is missing.
  Java, .NET and Go frameworks are Not yet. The stand-in for your agent's model now also speaks
  Claude's and Amazon Bedrock's formats; Google Gemini is Partial.
- **Put Geometer in front of your MCP servers.** `geo mcp wrap` shows a preview and then adds
  a small relay in front of each server in your MCP configuration; `geo mcp unwrap` puts the
  file back exactly. `geo mcp try` runs your own agent against a simulated service with a lost
  reply or a crash and says which rules held. A try can be kept as a check that `geo ci`
  replays. Or run `npx @geometer/init` in your project folder: it finds or installs `geo`,
  offers Docker set-up, shows the wrap and asks before writing.
- **Simulated services for more kinds of work.** Ready-made stand-ins for Stripe and Adyen
  (payments), Shopify, Zendesk and Intercom (commerce and support), and Salesforce, HubSpot and
  NetSuite (CRM and ERP). They are simulations modelled on each provider's public documentation,
  never the real services, and they cover only part of what each provider offers.
- **Learn a stand-in from your own service.** `geo mcp record` keeps a redacted record of a
  session on your computer, after it asks, and `geo mcp twin` turns it into a simulated copy
  that `geo mcp try` and `geo check` can use. A call the recording never showed is answered
  "not simulated", and the check says it could not tell.
- **Use it from your coding assistant.** `geo mcp serve` lets Claude Code or Cursor run a
  check, explain a problem and check your fix. Keeping the check always needs your OK in
  Geometer.
- **Docker set up where you are.** If Docker is missing or stopped, the terminal, the
  installer and the workspace's Docker card show the exact commands and ask first, and your
  coding assistant passes on a link to that card.
  `geo doctor --fix` does it without running a check. Scripts and CI are never asked: they get
  one message and exit code 3.
- **Honest results.** A check whose agent fails at start, or never calls a tool, now says
  "Couldn't run" or "Couldn't tell" (exit code 3, no certificate) instead of a clean result,
  and a project's own test command that cannot run in the sandbox is not counted as a problem.
- **A calmer workspace.** The board brings the old Overview, Explore and Authority screens
  together next to Guard and Prove, in plainer words; "Check my fix" works after you edit the
  code in place; `geo practice` sets up a practice project (with a games version), and there is an agent
  checklist page. The Mac app now carries the `geo` command and offers to add it to your
  terminal (it asks first and uses no `sudo`).
- **Guard and rules.** A rule can bound a number in a call, such as a refund amount: Geometer
  checks it and Guard enforces it. Guard records one entry for each MCP tool call it handles.
- **Geometer agents.** Fourteen small open agents under Apache-2.0, eight of them each built
  on a different framework, to try Geometer on or take as a starting point:
  https://github.com/GeometerLabs/agents. They span games and live worlds, commerce and
  support, money movement and operations.

Everything from 0.1.0-alpha.1 is still here: finding where your agent breaks a rule, replaying
the problem, checking your fix, kept checks in CI, the trust file, Guard in front of a tool,
signed certificates and Under the hood.

## Install

- **Mac app:** download the `.dmg`, drag Geometer to Applications, then allow it once in System Settings →
  Privacy & Security → Open Anyway (the alpha is not signed by Apple yet). This is needed again for each version.
- **Terminal, macOS or Linux:** `curl -fsSL https://geometer.dev/install.sh | sh` (checks the digest and installs
  for your user, without administrator rights). Running it again upgrades; `--rollback` goes back.
- **Linux CI:** `ghcr.io/geometerlabs/geo:0.1.0-alpha.2` (see the README).

Step-by-step instructions: https://geometer.dev/docs/install

## Check your download

Download `SHA256SUMS` into the same folder as the file, then:

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing     # macOS
sha256sum -c SHA256SUMS --ignore-missing         # Linux
```

Each line should end in `OK`. `release.json` lists every file with its platform, size and digest, and says that
nothing in this release is signed or notarized.

## Known limits

The full list is on the [Alpha limits](https://geometer.dev/docs/alpha-limits) page. The main ones:

- **Not signed by Apple.** macOS asks you to allow the app once for each version.
- **Apple silicon only on macOS**; no Intel Macs, no Windows, no Linux desktop app (on
  Linux, `geo open` opens the workspace in your browser).
- **Agents Geometer can run** are those whose tools it can find and simulate. When it
  cannot, it says what is missing instead of reporting a clean result. Supported means a real
  agent of that kind was checked from start to finish, not that every agent of that kind works.
- **Outside services and models are simulated.** A check shows how your agent behaves against
  those stand-ins, not against the real services or a real model. The service packs cover only
  part of what each provider offers.
- **Guard is for trying in development and staging.** It has not been qualified for
  production traffic.
- **Certificates are signed with a key made on your computer**, so they show integrity,
  not who issued them. Certificate links are built but not switched on.
- **Several parts have been tested only in part**: starting Docker for you on a computer that
  lacks it, the `geo` command inside the Mac app, and the Cursor setting. Each is named on the
  Alpha limits page.
- Geometer has been used by its own team only. Your reports decide what we fix first.
