# Security

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/GeometerLabs/geometer/security/advisories/new),
not in a public issue. Say which version and platform you used and how to reproduce it.
We will reply in the advisory.

Geometer runs on your computer and talks to its own workspace on `127.0.0.1` only. Each
release lists the SHA-256 digest of every file in `SHA256SUMS`; check it before you
install. The alpha is not signed by Apple yet.
